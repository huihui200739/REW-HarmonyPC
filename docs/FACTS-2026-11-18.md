## 3. 排除的误解

- **`github.com/rewtools/rew` 不是 REW**。它的描述是 "Capture failed Go builds into portable capsules. Replay them offline with Docker."，语言 Go，Apache-2.0，最新 commit `07eeb4d8`（2026-10-19）。与声学测量无关。
- GitHub 搜索结果里与 REW 相关的都是第三方周边（MCP server、EQ 预设转换脚本），没有本体源码。

## 4. 由此确定的路线

界面/图标要与原版一致 ⇒ 必须运行原版 jar ⇒ 必须在 OHOS 上提供 Java 8 运行时 + AWT/Swing + Java Sound。
重写路线（ArkTS 界面 + 自研 DSP）从定义上就无法做到"界面一样"，仅作为最后兜底。
